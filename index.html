Version history without extra tools

Autosave without giving up the past.

Under the hood, each project uses Git—the same reliable technology developers use to keep versions of their work. WritersStudio handles it for you: it makes automatic save points, lets you name a version, open an older draft without changing the current one, or continue from that point as a separate version. You never need to open a terminal.

Practical details

A few straight answers.

Is the desktop app really free?

Yes. There is no trial period and no subscription for the desktop app. It will remain free. The planned Cloud service may be paid, but it will be optional.

Do I need an account or internet connection?

No. Writing, search, export, and version history work offline. You only need internet access to download the app or use future online services.

Where does my manuscript live?

In the project folder you chose. The manuscript is stored as Markdown alongside the files WritersStudio uses to describe the project.

Will uninstalling remove my projects?

No. Uninstalling the app leaves your project folders where they are.

Is WritersStudio open source?

No. Our public GitHub repositories host official installers, release notes, and the standalone sample project; they do not contain or license the application source code.

Which platforms are available?

Windows is the first public platform. The download section reads the official GitHub releases and will show macOS when a macOS build is actually published.
