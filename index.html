Files on your computer

Pick a folder.
That is where the project lives.

WritersStudio does not require an account or an internet connection. A project stays in the folder you selected, where you can see it and back it up with any tool you already use.

01

You choose the location

Choose a folder on your computer or an external drive. Uninstalling WritersStudio leaves your projects in place. Keep a separate backup of important work.

02

Readable formats

The manuscript is stored as Markdown beside WritersStudio's project files. You can copy the whole folder whenever you like.

03

Copies you can take elsewhere

Export selected sections to DOCX or PDF, or make a ZIP copy of the entire project.

Version history without extra tools

Autosave without giving up the past.

WritersStudio uses Git to keep local versions of your project. Create a named save point, preview an earlier draft, or continue from it on a separate story branch. The app handles the version history; you do not need a terminal. History is stored with your project, so keep a separate backup too.

Practical details

Common questions.

Is the desktop app really free?

Yes. There is no trial period and no subscription for the desktop app. It will remain free. The planned Cloud service may be paid, but it will be optional.

Do I need an account or internet connection?

No account is needed. Writing, search, export, and version history work offline. The app uses internet access to check for updates. It sends usage events only if you enable optional analytics; manuscripts are not included.

Where does my manuscript live?

In the project folder you chose. The manuscript is stored as Markdown alongside the files WritersStudio uses to describe the project.

Will uninstalling remove my projects?

No. Uninstalling the app leaves your project folders where they are.

Is WritersStudio open source?

No. The public release repository contains official installers and release notes, but not the application's source code.

Which platforms are available?

The first public beta is for Windows x64. macOS is in development and is not available yet.
