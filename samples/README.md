# WritersStudio sample projects

Sample projects demonstrate WritersStudio with substantial, realistic content.
They are portable project folders rather than application source code.

| Sample                                        | Language | Highlights                                                                       |
| --------------------------------------------- | -------- | -------------------------------------------------------------------------------- |
| [Pride and Prejudice](./pride-and-prejudice/) | English  | Complete novel, demo drafts, outlines, characters, relations, and story timeline |

Copy a sample project to a separate writable folder before opening it. A sample
inside a cloned release repository sits beneath that repository's Git history;
copying it first gives WritersStudio a clean boundary for optional local
History.
