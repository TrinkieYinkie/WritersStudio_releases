# Pride and Prejudice — WritersStudio sample

A complete English sample project based on Jane Austen's _Pride and
Prejudice_. It is designed to demonstrate how a substantial novel can be
organized inside WritersStudio.

## Before opening the project

1. Copy the entire `pride-and-prejudice` folder to a separate writable
   location outside this release repository.
2. Open the copied `project.writersstudio` file, or choose the copied folder
   from WritersStudio's project picker.
3. After the project opens, turn on local History if you want save points and
   story branches in the copied project.

The portable sample has History recording switched off intentionally. If the
repository was cloned with Git, opening the project in place would put it under
the release repository's existing Git boundary. Copying the folder first keeps
product History separate from the repository used to distribute releases.

## What the completed sample contains

- **Final Manuscript** — the full 61-chapter novel arranged in three volumes.
- **Demo Drafts** — five modern revision exercises for selected scenes.
- **Outline and Notes** — nine documents covering the three volumes, themes,
  locations, relationships, and editorial conventions.
- **Characters** — 15 structured profiles with shared custom fields and links
  to relevant chapters.
- **Story Timeline** — 36 principal events across five filterable relationship
  threads, with links to chapters and participating characters.

## A quick five-minute tour

1. In **Final Manuscript**, expand **Volume I** and open **Chapter 3**.
2. Open **Meryton Assembly — Scene Pass** beside the published chapter to see
   how working material can link back to a final document.
3. Open **Elizabeth Bennet** in Characters and review the shared profile
   fields.
4. In **Story Timeline**, filter by **Elizabeth & Darcy**.
5. Open **Darcy's First Proposal**, then follow its related-document link to
   Chapter 34.

> [!IMPORTANT]
> The Demo Drafts, outlines, profiles, and timeline are modern sample material.
> They are not original or historical Jane Austen drafts.
