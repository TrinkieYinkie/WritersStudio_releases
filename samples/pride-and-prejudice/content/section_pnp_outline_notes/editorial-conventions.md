# Editorial Conventions

## Source boundary

Only documents in **Final Manuscript** reproduce the public-domain novel. All other content is modern sample material made for WritersStudio.

## Chapter numbering

File names and project titles use Arabic numbers for easy sorting. Chapter headings retain Roman numerals to echo the source edition.

## Timeline scope

The timeline follows narrative order and major causal beats. Austen does not provide a fully explicit calendar, so the sample avoids invented exact dates.

## Character fields

When the novel does not state an age or physical detail, profiles say so instead of converting adaptations or common assumptions into fact.

## Spelling and punctuation

The final text follows the pinned Standard Ebooks transcription documented in `SOURCES.md`. Demo materials use contemporary English editorial prose.

## History setting

History recording is off in this repository copy. Copy the sample outside the Git repository before enabling History, so its internal repository is not nested under this public one.
